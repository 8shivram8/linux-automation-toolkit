# Linux Automation Toolkit 🧰

A small set of Bash scripts that automate common Linux admin tasks:
- Create users easily
- Backup home folders
- Clean old logs
- Monitor services

## How to Run

1 Clone this repo
2 Go to scripts folder 
3 run {chmod +x *.sh}
4 Execute each Scripts with sudo

Example 

./create-user.sh devopsuser
./backup-home.sh devopsuser
./log-cleanup.sh
